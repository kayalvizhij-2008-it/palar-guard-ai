# Taste: Distinctive Aesthetic Direction & Anti-Template Design

Default AI code generates the same cookie-cutter UI: centered headlines, generic blue/violet button, floating three-card grid, and stock illustration. Taste enforces deliberate art direction.

## Core Rules for Superior Aesthetic Quality

1. **Domain Context Grounding**:
   - PALAR GUARD AI is an Environmental DeepTech and Water-Risk Decision Platform.
   - It belongs in the world of hydrological monitoring, environmental conservation, geographical surveys, and decision rooms.
   - Surfaces must reflect deep forest greens (`#062319`, `#0b3b2c`), emerald accents (`#10b981`), mineral charcoal (`#121614`), and warm ivory (`#fcfbf7`).

2. **Asymmetry & Visual Gravity**:
   - Avoid symmetric 3-column feature grids that repeat identically.
   - Utilize dynamic bento-style compositions: wide anchor card paired with compact data meters and status monitors.

3. **Restrained Elegance over Flash**:
   - No gratuitous 3D models spinning aimlessly without purpose.
   - Use 3D when it delivers authentic information: an interactive digital twin of the Palar River Basin with real hydrological elevation and flow lines.

4. **Real Data & Honest Representation**:
   - Never fabricate live API streams or invent fake sensor stations.
   - Clearly delineate between verified ground measurements, historical government records, and synthetic demonstration datasets.
