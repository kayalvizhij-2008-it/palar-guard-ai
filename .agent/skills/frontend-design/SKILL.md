# Anthropic Frontend Design Guide

Think and act as a Principal Frontend Architect and Senior Design Systems Engineer.

## Principles of Deliberate Execution

1. **Context-Specific Persona & Tone**:
   - Before writing code, commit to a defined visual voice appropriate for the user's domain.
   - For PALAR GUARD AI: Serious, institutional-grade, scientific, authoritative, yet modern and exceptionally crafted.

2. **Typography as Personality**:
   - Do not settle for default system fonts without styling.
   - Pair a refined display typeface for titles with a clean, high-legibility geometric/neutral sans for UI labels, and monospaced tabular figures for all environmental metrics.

3. **Defensive UI Engineering**:
   - Every interactive control must provide loading, disabled, hover, active, and error states.
   - Handle empty states gracefully with actionable guidance.
   - Maintain structural stability: avoid layout jumps during image loading or data fetching.
